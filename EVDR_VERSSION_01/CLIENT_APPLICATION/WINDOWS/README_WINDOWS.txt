SERVO EVDR APPLICATION - Windows Package

How to run:
1. Open folder: SERVO_EVDR_APPLICATION
2. Run: SERVO_EVDR_APPLICATION.exe

Important:
- Keep all files inside the SERVO_EVDR_APPLICATION folder.
- Do not move only the EXE by itself.

Transport notes:
- Serial: Select COM port and connect.
- BLE: Turn ON Bluetooth + Location on Windows, then scan and connect.
